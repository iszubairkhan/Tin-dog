# 🐶 TinDog

> **Meet new and interesting dogs nearby.** — A modern, responsive landing page for a fictional Tinder-style dating and social matchmaking app for dogs.

---

## 📌 Project Overview

**TinDog** is a marketing landing page designed to showcase a modern mobile application concept. The project focuses on clean design hierarchy, compelling conversion sections, responsive mobile-first grids, and smooth visual storytelling to engage visitors and drive app downloads.

---

## ✨ Key Sections & Features

* 📱 **Hero Showcase:** High-impact call-to-action (CTA) header featuring direct download links for iOS and Android alongside an angled device mockup.
* 🐾 **Value Proposition:** 3-column feature grid highlighting core user benefits (Ease of Use, Elite Canine Matchmaking, and Guaranteed Satisfaction).
* 💬 **Testimonial Carousel:** Social proof slider featuring humorous canine customer reviews and featured media press badges.
* 💳 **Tiered Pricing Matrix:** Structured, comparative pricing cards (*Chihuahua*, *Labrador*, and *Mastiff* plans) engineered for clean responsive alignment.
* 📲 **Footer CTA:** Final conversion push prompting users to find their pet's true love, complete with social navigation icons.

---

## 🛠️ Tech Stack

* **Markup:** Semantic HTML5
* **Styling & Grid:** CSS3, Bootstrap Framework (Responsive Grid System, Flexbox, Cards, and Carousel components)
* **Icons & Fonts:** Font Awesome icons & Google Fonts (Montserrat, Ubuntu)
* **Deployment:** GitHub Pages
